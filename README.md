# 🔥 Calorie Burn Prediction Using XGBoost

This project uses machine learning to **predict the number of calories burnt** by individuals during physical activity. The model analyzes various features like age, gender, weight, height, and activity metrics to provide accurate calorie burn estimates.

---

## 🧠 Overview

This project implements a **regression model using XGBoost** to predict calories burned based on key biometric and exercise-related inputs. It leverages data visualization, preprocessing, and evaluation techniques using tools like **NumPy, Pandas, Seaborn, Matplotlib**, and **Scikit-learn**.

---

## 📊 Dataset

- **Source**: https://www.kaggle.com/datasets/ruchikakumbhar/calories-burnt-prediction
-  **Rows**: ~1,500
- **Columns**: 
  - `Gender`
  - `Age`
  - `Height`
  - `Weight`
  - `Duration`
  - `Heart_Rate`
  - `Body_Temp`
  - `Calories`
